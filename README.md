# DAMIRKA-Launcher
DAMIRKA Launcher — сетевой лаунчер на C# для управления и запуска всех твоих игр и эмулятора WAW. Связывается по сокетам с легким сервером на Ubuntu, автоматически обновляет файлы проектов, считывает данные из JSON и имеет крутой темный интерфейс в хакерском стиле. Экономит ОЗУ сервера.

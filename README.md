# 🚀 DAMIRKA Launcher

Сетевой лаунчер на **C#** для управления и запуска проектов. Связывается по сокетам с легковесным сервером на **Ubuntu**, динамически загружает список программ и автоматически скачивает обновления.

## 🟢 Особенности
* **Network Dynamic:** Список проектов загружается из `projects.json` на сервере.
* **Auto-Update:** Сравнивает локальные версии файлов с серверными и скачивает патчи.
* **Low Memory:** Серверная часть на Python тратит всего 15–30 МБ ОЗУ на Ubuntu.
* **Hacker UI:** Стильный темный киберпанк-интерфейс на моноширинных шрифтах.

## 🛠️ Структура файлов
* `server.py` — серверный скрипт для Ubuntu (порт 5000).
* `projects.json` — текстовая база данных со списком проектов.
* `DamirkaLauncher/` — исходный код клиента на C# (WPF/WinForms).
